# Древнегреческий учебник в кармане

Интерактивное веб-приложение для изучения древнегреческого языка Нового Завета
по учебнику Дж. Грешема Мейчена. Уроки 1–10.

**Открыть приложение:** https://grandiozova.github.io/greek_bot/

## Возможности

- 10 уроков: грамматика, словарь и упражнения
- Упражнения на склонение, определение падежа и числа, перевод с греческого и на греческий
- Карточки для запоминания слов
- Тесты для самопроверки
- Разбор молитвы «Отче наш» с пословным переводом
- Отслеживание прогресса и работа над ошибками
- Светлая и тёмная темы, интерфейс для телефона и компьютера

## Как пользоваться

Откройте ссылку выше в браузере — установка не нужна.
Прогресс сохраняется локально в вашем браузере.

Чтобы запустить локально, склонируйте репозиторий и откройте `index.html`
в браузере. Приложение состоит из одного файла и не требует сборки или сервера.
