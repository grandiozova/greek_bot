Интерактивное веб-приложение для изучения древнегреческого языка по учебнику Дж. Грешема Мейчена.
Проект некоммерческий, образовательный, код доступен на GitHub.

**Возможности**

- 10 уроков с грамматикой, словарём и упражнениями
- Интерактивные упражнения на склонение, перевод, падежи
- Карточки для запоминания слов
- Тесты для самопроверки
- Разбор молитвы «Отче наш»
- Сохранение прогресса

**Источник учебных материалов**

Упражнения, грамматика и лексика основаны на учебном материале:
Дж. Грешем Мейчен. Учебник греческого языка Нового Завета / Перевод с английского А. А. Руденко; 
Научный редактор Е. Б. Смагина. — Москва : Российское Библейское общество, 2024. ISBN 978-5-85524-292-8.
Оригинальное издание: J. Gresham Machen. New Testament Greek for Beginners. — First published in 1923
