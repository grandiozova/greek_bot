# НББС, «Грамматика древнееврейского языка» — машиночитаемая версия

Справочник по учебному пособию, по которому будут составляться еврейские уроки
приложения. Нужен для одного: когда просят «добавь в приложение то-то из
пособия», найти это здесь и перенести в `data/hebrew-lessons.js`.

**Начинать с [INDEX.md](INDEX.md)** — там карта глав, темы и страницы.

## Что это за книга

| | |
|---|---|
| Заглавие | Учебное пособие по грамматике древнееврейского языка, 1-й год обучения |
| Издатель | Новосибирская библейская богословская семинария (НББС) |
| Год | 2011 |
| Основа | Gary D. Pratico, Miles V. Van Pelt, *Basics of Biblical Hebrew Grammar* |
| Объём | 273 страницы; введение + 36 глав |
| Расшифровано | главы 1–11, стр. 5–91 |

Сам PDF в репозиторий не кладётся (авторское право). Здесь только текст.

## Структура

```
INDEX.md                        карта книги: глава -> темы, страницы, файл
front-matter.md                 выходные данные и что ещё не расшифровано
lessons/lesson-01.md .. -11.md  главы целиком (грамматика + таблицы + словарь)
restoration-report.md           отчёт: как расшифрован еврейский шрифт
data/vocabulary-by-lesson.json  словарь каждой главы, разобранный по статьям
tools/                          скрипты сборки (к приложению не подключены)
tools/raw/lesson-NN.txt         исходная транскрипция, ещё в шрифтовой кодировке
```

Каждая страница помечена в тексте маркером `[p. 21]` — это **номер страницы
книги**. По маркеру удобно сослаться на источник и найти место в оригинале.

## Главное отличие от греческого справочника

[Греческий справочник](../machen-nt-greek/README.md) восстанавливали после OCR:
слой ABBYY потерял политонику целиком, её пришлось добирать вторым проходом
распознавания, и 707 слов (5%) так и остались непроверенными.

**Здесь ничего не распознавалось.** В PDF еврейский текст записан не буквами
Юникода, а латиницей в шрифтовой кодировке **BWHEBB** (BibleWorks Hebrew):
слово דָּבָר хранится как строка `rb'D"`. Это **обратимое однозначное
отображение**, а не результат распознавания. Расшифровка выполняется
программой [`tools/unfont.py`](tools/unfont.py) и не содержит догадок.

Практический вывод: еврейские формы здесь можно брать **как есть**, сверять
с отчётом по каждому слову, как в греческом, не нужно. Проверять надо не
формы, а **транскрипцию**: см. ниже.

## Что здесь может быть не так

Слабое звено — не расшифровка, а ручная транскрипция книги в
`tools/raw/lesson-NN.txt`. Каждый еврейский отрезок в этих файлах обёрнут в
угловые скобки `⟨…⟩` (U+27E8/U+27E9):

```
Прилагательное ⟨bwOj⟩ «хороший» согласуется с существительным.
```

Разметка обязательна: без неё «Qal», «sg.» и «BHS» неотличимы от еврейского
текста и были бы расшифрованы как еврейские слова. Что внутри `⟨⟩` — то и
расшифровывается, остальное не трогается.

Это же даёт механическую проверку. `unfont.py --audit` выводит третьей
колонкой глифы, которых нет в таблице, — то есть места, где транскрипция
испорчена. Проверка поймала две настоящие ошибки; какие именно — в
[restoration-report.md](restoration-report.md).

Сейчас по всем 11 главам: **1775 отрезков, 2017 еврейских слов,
0 неизвестных глифов**.

## Как пользоваться

1. Открыть [INDEX.md](INDEX.md), найти главу или тему.
2. Прочитать `lessons/lesson-NN.md` — грамматика, таблицы и словарь целиком.
3. Для словаря взять [`data/vocabulary-by-lesson.json`](data/vocabulary-by-lesson.json).
   У каждой статьи есть `freq` — частота слова в еврейской Библии, её даёт
   само пособие. Этого признака в греческих данных нет, а по нему удобно
   отбирать, скажем, первые 200 самых частотных слов.
4. Переносить в `data/hebrew-lessons.js` в том же формате урока, что и
   греческий (`title`, `grammar`, `vocabulary`, `exercises`, `translation`) —
   см. `AGENTS.md` в корне репозитория.

**Еврейский текст пишется справа налево.** Всё, что попадёт в приложение,
должно быть в контейнере с `dir="rtl"` — в греческом коде такого нет ни
одного, это отдельная задача (фаза 2 плана).

**Огласовку не «нормализовать».** Порядок знаков в расшифрованном тексте
намеренно не приведён к NFC — почему, объяснено в
[restoration-report.md](restoration-report.md). То же правило, что и для
греческой диакритики в `AGENTS.md`: не трогать.

## Пересборка

Из каталога `tools/`:

```
python unfont.py --self-test              # 19 контрольных слов
python unfont.py --stats raw/lesson-*.txt # сводка, неизвестных глифов быть не должно
python unfont.py raw/lesson-*.txt -o ../lessons/
python build_vocab.py                     # data/vocabulary-by-lesson.json
python build_meta.py                      # tools/meta.json
python build_index.py                     # INDEX.md
```

Порядок важен: `build_index.py` читает то, что написали два предыдущих шага.
Подробнее — [tools/README.md](tools/README.md).

Файлы `lessons/*.md`, `data/*.json`, `tools/meta.json` и `INDEX.md`
**собираются**. Правки вносят в `tools/raw/lesson-NN.txt` и пересобирают,
иначе поправка потеряется.
