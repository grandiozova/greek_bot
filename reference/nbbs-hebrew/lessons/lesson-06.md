## 6.1 Введение

Предлоги в древнееврейском языке используются для описания взаимосвязи между
словами. Слово, стоящее после предлога, называется **объектом предлога**.
Предлоги древнееврейского языка можно разделить на три группы: **независимые**
(пишутся отдельно от своего объекта), **предлоги, присоединяющиеся через
маккеф**, и **неотделяемые (слитные)** предлоги (пишутся слитно со своим
объектом).

## 6.2 Независимые предлоги

Большинство предлогов в древнееврейском языке пишутся отдельно от следующего
слова.

| | | | |
|---|---|---|---|
| לִפְנֵי הַמֶּ֫לֶךְ | пред царём | אַחַר הַמַּבּוּל | после потопа |
| תַּ֫חַת הָעֵץ | под деревом | בֵּין הַמַּ֫יִם | между водами |

## 6.3 Предлоги, присоединяющиеся к слову через маккеф

Предлоги этой группы всегда присоединяются к своему объекту через **маккеф** —
короткую чёрточку в верхней части строки. К наиболее употребительным предлогам
данной группы относятся: עַל־ (на, над; о), אֶל־ (к, в), עַד־ (до,
вплоть до) и מִן־ (из, от).

| | | | |
|---|---|---|---|
| עַל־הָאֶ֫בֶן | на камне | עַד־הַנָּהָר | до реки |
| אֶל־הַהֵיכָל | к храму | מִן־הָאָ֫רֶץ | из земли |

## 6.4 Слитные (неотделимые) предлоги

Эти предлоги всегда пишутся слитно со следующим словом. Таких предлогов три:¹

- בְּ — в, передаёт также значение творительного падежа
- לְ — к, передаёт значение дательного падежа
- כְּ — как

¹ Несмотря на то, что неотделяемых предлогов в древнееврейском языке всего лишь
три, вместе они встречаются в Еврейской Библии 38 932 раза: בְּ (15 559),
כְּ (3053) и לְ (20 321).

[p. 44]

1. Перед большинством согласных слитные предлоги пишутся с «произносимым» шва:
   בְּ, לְ или כְּ (в своей словарной форме).

| | |
|---|---|
| בְּשָׂדֶה | в поле |
| לְנַ֫עַר | к молодому человеку |
| כְּמֶ֫לֶךְ | как царь |

2. Если слово начинается на гортанный согласный со сверхкратким гласным (*ă,
   ĕ, ŏ*), то слитные предлоги содержат краткий гласный того же качества.

| | |
|---|---|
| כַּאֲנָשִׁים | как люди |
| בֶּאֱמֶת | в истине |
| לָחֳלִי | к болезни |

3. Перед согласными с «произносимым» шва слитные предлоги пишутся с хиреком,
   ввиду того, что два «произносимых» шва не могут стоять рядом в начале слова.

| | |
|---|---|
| לִנְבִיאִים | к пророкам |
| לִבְרִית | к завету |

4. При наличии у существительного определённого артикля эти предлоги сливаются
   с ним в один слог: начальный ה артикля поглощается, в результате чего
   первый согласный слова удваивается, а гласный артикля переходит к предлогу.

| | | | |
|---|---|---|---|
| שָׂדֶה | поле | הַשָּׂדֶה / בַּשָּׂדֶה | (это) поле / в (этом) поле |

[p. 45]

| אֵשׁ | огонь | הָאֵשׁ / בָּאֵשׁ | (этот) огонь / в (этом) огне |
| נַ֫עַר | мальчик | הַנַּ֫עַר / לַנַּ֫עַר | (этот) мальчик / (этому) мальчику |
| מֶ֫לֶךְ | царь | הַמֶּ֫לֶךְ / כַּמֶּ֫לֶךְ | (этот) царь / как (этот) царь |

## 6.5 Предлог מִן

Этот предлог заслуживает особого внимания, потому что он может писаться слитно
со словом или присоединяться к нему через маккеф.

1. Часто предлог מִן присоединяется к своему объекту через маккеф:
   מִן־הַבַּ֫יִת «из дома» или מִן־הַמַּלְכָּה «от царицы». В такой неслитной
   форме предлог מִן встречается почти исключительно перед артиклем.
2. Как правило, предлог מִן пишется слитно со словом. В этом случае נ
   предлога ассимилирует в первый согласный существительного. Сочетание
   заменяется удвоением этого согласного, в результате чего предлог имеет форму
   מִ, а в первой букве слова ставится «сильный» дагеш. Например:
   מִן־מֶ֫לֶךְ «от царя» → מִמֶּ֫לֶךְ «от царя».

   a. То же происходит, когда слово начинается на согласный группы
      «бегадкефат»: בַּ֫יִת «дом», מִבַּ֫יִת «из дома».
   b. Когда מִן пишется слитно со словом на гортанный или ר, происходит
      **заместительное удлинение** гласного. Краткий *i* (хирек) предлога
      удлиняется до долгого *ē* (цере), и предлог имеет форму מֵ, например:
      מֵאִישׁ «от человека» или מֵעִיר «из города». Когда מִן
      присоединяется к слову с артиклем, ה артикля остаётся:
      מֵהָאָ֫רֶץ «из земли».

[p. 46]

   c. Когда מִן пишется слитно со словом на ח, первый согласный не
      удваивается, но при этом не происходит и заместительного удлинения:
      מִחוּץ «снаружи». Это явление называется **скрытым удвоением**. Однако
      в других случаях будет иметь место заместительное удлинение, например:
      מֵחֶ֫רֶב «от меча».

## 6.6 Способы употребления предлога מִן

Ввиду высокой частоты встречаемости מִן (7592 раза), стоит изучить несколько
особых случаев его употребления.

1. **Для выражения сравнительной степени.**

   טוֹבָה חָכְמָה מִזָּהָב — букв. «Мудрость хороша от золота» → «Мудрость
   лучше золота».

   טוֹב הַסֵּ֫פֶר הַזֶּה מִן־הַסֵּ֫פֶר הַהוּא — букв. «Эта книга хорошая от той
   книги» → «Эта книга лучше той книги».

   При таком способе употребления предлог מִן может передавать идею
   «слишком… для»: קָשָׁה הָעֲבוֹדָה מֵהָאֲנָשִׁים — «(Эта) работа слишком
   трудна для людей».

2. **Для выражения превосходной степени.** Предлог מִן со словом כֹּל
   «весь, любой, каждый» может передавать значение превосходной степени,
   מִכֹּל буквально «от каждого».

   עָרוּם מִכֹּל חַיַּת הַשָּׂדֶה — букв. «Умный от каждого живого существа
   полевого» → «Умнейший из всех живых существ полевых».

[p. 47]

3. **Разделительный способ употребления** — описание части от целого.

| | | |
|---|---|---|
| מִפְּרִי | от плодов | часть плодов |
| מֵהָאֲנָשִׁים | из людей | часть людей |

## 6.7 Показатель прямого дополнения

В еврейской прозе определённое прямое дополнение обычно отмечается частицей
אֶת־ / אֵת. Прямое дополнение — это тот член предложения, на который
направлено действие глагола. Определённым прямым дополнением называется такое
дополнение, которое употребляется с определённым артиклем. Показатель
определённого прямого дополнения пишется точно так же, как предлог אֶת־ /
אֵת «с». В большинстве случаев они различаются по контексту.

כָּתַב אֶת־הַדְּבָרִים בַּסֵּ֫פֶר — «Он написал (эти) слова в (этой) книге.»

Обратите внимание на то, что показатель определённого прямого дополнения не
переводится.

| | |
|---|---|
| בָּרָא אֱלֹהִים אֵת הַשָּׁמַ֫יִם | Бог сотворил (эти) небеса. |
| נָתַן הַנָּבִיא אֶת־הַסֵּ֫פֶר לַמֶּ֫לֶךְ | Пророк отдал (эту) книгу царю. |
| בָּנָה הַמֶּ֫לֶךְ אֶת־הַהֵיכָל הַגָּדוֹל | Царь построил (этот) великий храм. |

[p. 48]

Имена собственные (שְׁמוּאֵל «Самуил») и существительные с местоименными
суффиксами (סוּסִי «моя лошадь») также считаются определёнными.

| | |
|---|---|
| שָׁמַר הַמֶּ֫לֶךְ אֶת־הַמִּצְוָה וְאֶת־הַתּוֹרוֹת | Царь соблюдал (эти) заповеди и (этот) закон. |
| שָׁלַח הַנָּבִיא אֶת־הַמַּלְאָךְ אֶל־הָעִיר | Пророк отправил (этого) посланника в город. |
| אָהַב דָּוִד אֶת־יְהוֹנָתָן | Давид любил Ионафана. |

Перед неопределённым дополнением показатель определённого прямого дополнения
не ставится.

| | |
|---|---|
| בָּנָה הַמֶּ֫לֶךְ הֵיכָל גָּדוֹל | Царь построил великий храм. |

## 6.8 Краткое содержание главы

1. В еврейском языке есть три группы предлогов: независимые, присоединяющиеся
   через маккеф, и неотделяемые.
2. Неотделяемые предлоги בְּ, לְ и כְּ всегда пишутся слитно со словом.
3. Предлог מִן может присоединяться через маккеф или писаться слитно. Когда
   слитно, נ предлога ассимилирует в первый согласный существительного.
4. Предлог מִן может употребляться для выражения сравнительной степени,
   превосходной степени и для указания на часть целого.
5. Определённое прямое дополнение обычно отмечается частицей אֶת־ / אֵת.
   Показатель прямого дополнения не переводится.

## 6.10 Кто как Ты?

Из так называемых малых пророков современным читателям более-менее хорошо
известен Михей. Со ссылкой на уникальное сочетание божественной справедливости
и божественной милости, в конце книги пророк провозглашает כָּמוֹךָ מִי־אֵל
(7:18). Простая грамматическая конструкция: вопрос состоит из вопросительного
местоимения מִי, титула Бога אֵל и предлога כְּ с местоименным суффиксом
муж. рода 2-го лица ед. ч. (Кто Бог, как Ты?).

Имя Михей в еврейском языке состоит из вопросительного местоимения מִי,
предлога כְּ и сокращённой формы имени Бога (Кто как Яхве?). В еврейском
тексте безошибочно прослеживается связь между именем пророка и его посланием о
милости Бога в 7:18.

> Кто, как Ты, Господи, между богами?
> Кто, как Ты, величествен святостью,
> досточтим хвалами, Творец чудес?
> (Исх. 15:11)

## 6.11 Дополнительная информация: составные предлоги

1. Несколько часто используемых предлогов образованы от существительного
   פָּנֶה «лицо», которое найдено только во множественном числе (פָּנִים).

| | |
|---|---|
| לִפְנֵי | перед, в присутствии (לְ + פָּנִים) |
| מִפְּנֵי | от, из-за, по причине (מִן + פָּנִים) |
| מִלִּפְנֵי | от, из-за, по причине (מִן + לְ + פָּנִים) |
| עַל־פְּנֵי | перед, в присутствии, на виду у, около |

2. Предлоги, образованные путём объединения двух разных предлогов.

| | | |
|---|---|---|
| מֵעַל | от, из | מִן присоединяется к עַל |
| מִתַּ֫חַת | из-под | מִן присоединяется к תַּ֫חַת |
| מֵאֵת | от, из | מִן присоединяется к אֵת |

3. Предлоги, образованные присоединением предлога к существительному.

| | | |
|---|---|---|
| עַל־דְּבַר | ради, из-за | עַל + דָּבָר |
| בְּתוֹךְ | среди, внутри | בְּ + תָּ֫וֶךְ |
| מִתּוֹךְ | из, изнутри | מִן + תָּ֫וֶךְ |
