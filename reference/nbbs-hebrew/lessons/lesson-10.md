## 10.1 Введение

В древнееврейском языке нет склонения, и падежные значения, в основном,
выражаются с помощью предлогов. Однако значение родительного падежа
(принадлежность) выражается при помощи конструкции, называемой **сопряжённым
сочетанием**:

| | |
|---|---|
| קוֹל הָאִישׁ | голос человека |
| מֶ֫לֶךְ הָאָ֫רֶץ | царь земли |
| עֶ֫בֶד הַמֶּ֫לֶךְ | слуга царя |

Как показано в этих примерах, в сопряжённом сочетании изменяется форма
**первого** (определяемого) слова. Форма второго слова (определения) остаётся
неизменной. (В русском языке ситуация противоположная: второе существительное
ставится в родительном падеже, а первое остаётся в именительном.)

## 10.2 Грамматика сопряжённого сочетания

1. **Сопряжённая и абсолютная формы.** Первое из двух существительных
   сочетания называется «сопряжённым» и употребляется в **сопряжённой форме**,
   второе называется **абсолютным** и используется в абсолютной или своей
   словарной форме.

   В сопряжённом сочетании может быть несколько слов в сопряжённой форме, но
   лишь одно в абсолютной, и оно всегда стоит в конце цепи. **Между членами
   сопряжённого сочетания другие слова или частицы не ставятся.** Цепь нельзя
   разорвать.

2. **Определённость и неопределённость.** В сопряжённом сочетании либо оба
   члена определённые, либо оба неопределённые, однако **перед сопряжённой
   формой артикль не ставится**. Определённость сочетания зависит от
   абсолютной формы.

   Неопределённые сопряжённые сочетания:

| | |
|---|---|
| קוֹל אִישׁ | голос человека |
| מֶ֫לֶךְ אֶ֫רֶץ | царь земли |

[p. 75]

| עֶ֫בֶד מֶ֫לֶךְ | слуга царя |

   Определённые (абсолютная форма с артиклем):

| | |
|---|---|
| קוֹל הָאִישׁ | (этот) голос (этого) человека |
| מֶ֫לֶךְ הָאָ֫רֶץ | (этот) царь (этой) земли |
| עֶ֫בֶד הַמֶּ֫לֶךְ | (этот) слуга (этого) царя |

   Определёнными считаются 4 типа существительных: 1) с артиклем
   (הַמַּלְכָּה); 2) с местоименным суффиксом (סוּסוֹ); 3) имена собственные
   (שְׁמוּאֵל); 4) единственные в своём роде объекты (יָרֵחַ «луна»).

| | |
|---|---|
| אֲבִי אַבְרָהָם | (этот) отец Авраама |
| עֶ֫בֶד שְׁמוּאֵל | (этот) слуга Самуила |
| בֵּית מַלְכִּי | (этот) дом моего царя |
| סֵ֫פֶר אָבִ֫יהוּ | (эта) книга его отца |

3. **Сопряжённые сочетания с несколькими сопряжёнными формами.**

| | |
|---|---|
| עֶ֫בֶד אֲחִי הַמֶּ֫לֶךְ | слуга брата царя |
| עֶ֫בֶד בֵּית הַמֶּ֫לֶךְ | слуга дома царя |
| דִּבְרֵי מֶ֫לֶךְ הָאָ֫רֶץ | слова царя земли |

4. **Маккеф в сопряжённом сочетании.** Иногда члены сопряжённого сочетания
   соединяются через маккеф.

[p. 76]

| | |
|---|---|
| בֶּן־דָּוִד | сын Давида |
| כָּל־הָעָם | все из народа |
| בֵּית־אָבִי | дом моего отца |

## 10.3 Сопряжённые сочетания с прилагательными

1. **Прилагательные-определения.** Если один из членов сопряжённого сочетания
   имеет при себе прилагательное-определение, оно ставится **после** всего
   сопряжённого сочетания и согласуется с определяемым существительным в роде,
   числе и определённости.

| | |
|---|---|
| דְּבַר הַמַּלְכָּה הַטּוֹב | (это) доброе слово царицы (прил. муж. р. — к сопряжённой форме) |
| דְּבַר הַמַּלְכָּה הַטּוֹבָה | (это) слово доброй царицы (прил. жен. р. — к абсолютной форме) |
| מֶ֫לֶךְ הָאָ֫רֶץ הַטּוֹב | (этот) добрый царь земли |
| מֶ֫לֶךְ הָאָ֫רֶץ הַטּוֹבָה | (этот) царь доброй земли |

[p. 77]

2. **Указательное местоимение в функции определения** также ставится после
   сопряжённого сочетания.

| | |
|---|---|
| אֵ֫שֶׁת הָאִישׁ הַזֶּה | жена этого человека |
| דִּבְרֵי הַנָּבִיא הָאֵ֫לֶּה | эти слова пророка |
| דִּבְרֵי הַנָּבִיא הַזֶּה | слова этого пророка |

3. **Прилагательные в сопряжённой форме.**

| | | |
|---|---|---|
| יְפַת מַרְאֶה | красивый видом | (יְפַת — сопр. форма от יָפֶה) |
| חֲכַם־לֵב | мудрый сердцем | (חֲכַם — сопр. форма от חָכָם) |
| קְדוֹשׁ יִשְׂרָאֵל | Святой Израилев | (קְדוֹשׁ — сопр. форма от קָדוֹשׁ) |

## 10.4 Существительные в сопряжённой форме с неотделяемыми предлогами

Несмотря на то, что сопряжённая форма не употребляется с артиклем, она
употребляется с неотделяемыми предлогами (בְּ, לְ и כְּ), например:
בְּבֵית דָּוִד «в доме Давида».

## 10.5 Написание сопряжённой формы

Во многих случаях сопряжённая форма существительных единственного числа
совпадает со словарной формой, например: סוּס, קוֹל и מֶ֫לֶךְ. Однако у
большинства существительных сопряжённая и словарная формы отличаются, потому
что существительное в сопряжённой форме частично теряет своё ударение.

[p. 78]

1. **Редукция гласных.**

   a. В закрытом последнем слоге долгий *ā* (камец), а в некоторых словах и
      долгий *ē* (цере), переходят в краткий *а* (патах).

| Абсолютная форма | Сопряжённая форма |
|---|---|
| מִשְׁפָּט суд | מִשְׁפַּט |
| מִדְבָּר пустыня | מִדְבַּר |
| מַלְאָךְ ангел | מַלְאַךְ |
| מִזְבֵּחַ жертвенник | מִזְבַּח |

   b. В открытом безударном слоге долгий *ā* (камец) и долгий *ē* (цере)
      переходят в «произносимое» шва.

| Абсолютная форма | Сопряжённая форма |
|---|---|
| נָבִיא пророк | נְבִיא |
| שָׁלוֹם мир | שְׁלוֹם |
| מָקוֹם место | מְקוֹם |

   c. Часто применяются оба правила сразу.

| Абсолютная форма | Сопряжённая форма |
|---|---|
| דָּבָר слово | דְּבַר |
| לֵבָב сердце | לְבַב |
| קָהָל собрание | קְהַל |
| זָקֵן старейшина | זְקַן |
| חָצֵר двор | חֲצַר |

[p. 79]

   d. Односложные слова כֹּל «весь» и בֵּן «сын» чаще других встречаются в
      сопряжённой форме.

| Абсолютная форма | Сопряжённая форма |
|---|---|
| בֵּן сын | בֶּן |
| כֹּל весь | כָּל |
| יָד рука | יַד |

2. Окончания мужского рода множественного יִם и двойственного числа יִַם
   меняются на יֵ.

| Абсолютная форма | Сопряжённая форма |
|---|---|
| אֱלֹהִים Бог | אֱלֹהֵי |
| בָּנִים сыновья | בְּנֵי |
| עֵינַ֫יִם два глаза | עֵינֵי |
| דְּבָרִים слова | דִּבְרֵי |

3. Окончание הָ в сопряжённой форме существительных женского рода
   единственного числа заменяется на תַ.

| Абсолютная форма | Сопряжённая форма |
|---|---|
| תּוֹרָה закон | תּוֹרַת |
| מַלְכָּה царица | מַלְכַּת |
| שָׁנָה год | שְׁנַת |

4. Характерное окончание существительных женского рода множественного числа
   וֹת **сохраняется**.

[p. 80]

| Абсолютная форма | Сопряжённая форма |
|---|---|
| מַמְלָכוֹת царства | מַמְלְכוֹת |
| שֵׁמוֹת имена | שְׁמוֹת |
| שָׂדוֹת поля | שְׂדוֹת |
| בְּרָכוֹת благословения | בִּרְכוֹת |

5. К основе некоторых односложных существительных в сопряжённой форме
   добавляется хирек йод.

| Абсолютная | Сопряжённая | С местоименным суффиксом |
|---|---|---|
| אָב отец | אֲבִי | אָבִי мой отец |
| אָח брат | אֲחִי | אָחִי мой брат |

6. Небольшая группа существительных с последовательностью гласных יִַ
   меняет её на цере йод.

| Абсолютная форма | Сопряжённая форма |
|---|---|
| בַּ֫יִת дом | בֵּ֫ית |
| עַ֫יִן источник | עֵ֫ין |

7. **Сеголатные существительные.** Сопряжённая форма в единственном числе
   совпадает со словарной. Во множественном числе последовательность гласных
   такова: מַלְכֵי «цари».

[p. 81]

| Абсолютная форма | Сопряжённая форма |
|---|---|
| מֶ֫לֶךְ царь | מֶ֫לֶךְ |
| עֶ֫בֶד слуга | עֶ֫בֶד |
| מְלָכִים цари | מַלְכֵי |
| עֲבָדִים слуги | עַבְדֵי |

8. Существительные, оканчивающиеся на הֶ, в сопряжённой форме единственного
   числа оканчиваются на הֵ.

| Абсолютная форма | Сопряжённая форма |
|---|---|
| שָׂדֶה | שְׂדֵה |
| מַחֲנֶה | מַחֲנֵה |

## 10.6 Краткое содержание главы

1. Значение родительного падежа выражается сопряжённым сочетанием.
2. В сопряжённом сочетании может быть несколько слов в сопряжённой форме, но
   лишь одно в абсолютной, и оно всегда стоит в конце.
3. Определённость сочетания зависит от абсолютной формы; перед сопряжённой
   формой артикль не ставится.
4. Иногда члены соединяются через маккеф: בֶּן־דָּוִד «сын Давида».
5. Между членами сочетания не ставятся другие слова; прилагательное-определение
   идёт после всего сочетания.
6. К сопряжённой форме могут присоединяться неотделяемые предлоги.
7. Сопряжённая форма большинства существительных отличается от словарной.

## 10.8 Жениться на блуднице?

В Ос. 1 мы сталкиваемся с проблемой интерпретации: на самом ли деле Бог велел
Осии жениться на блуднице?

В еврейском языке есть три слова для обозначения блудницы: קְדֵשָׁה
(культовая проститутка), זֹנָה (обычная проститутка) и כֶּלֶב (мужчина,
занимающийся проституцией). Ни одно из этих трёх слов здесь не используется.
Вместо этого здесь обнаруживается особое выражение со словом в **сопряжённой
форме**: слово אִשָּׁה (в сопряжённой форме אֵ֫שֶׁת) используется в сочетании
с управляющим существительным во множественном числе мужского рода,
זְנוּנִים.

В еврейском языке использование множественного числа мужского рода является
стандартным способом выражения абстрактного понятия. В данном случае речь идёт
не о проститутке, а о понятии проституции, или разврата. Более того,
существительное в сопряжённой форме часто логически связано с управляющим им
существительным так, что оно обозначает «нечто, характеризующееся тем-то и
тем-то», так что выражение אֵ֫שֶׁת זְנוּנִים стремится к тому, чтобы означать
«женщина, характеризующаяся развратом», вместо того чтобы буквально означать
«проститутка».

## 10.9 Дополнительная информация: превосходная степень

Из раздела 6.6.2 вы узнали, что предлог מִן со словом כֹּל может
употребляться для образования превосходной степени (מִכֹּל). Но это только
один из нескольких способов.

1. Самый распространённый способ состоит в том, чтобы использовать
   прилагательное, сделанное определённым с помощью определённого артикля,
   местоименного суффикса или слова в сопряжённой форме.
2. Другой способ состоит в том, чтобы взять два существительных в форме
   сопряжённого сочетания, при этом существительное в сопряжённой форме должно
   быть в единственном числе, а существительное в абсолютной форме — быть
   определённым и стоять во множественном числе. В такой конструкции два
   существительных должны быть одинаковыми.

| | |
|---|---|
| קֹ֫דֶשׁ הַקֳּדָשִׁים | «святое святых», что значит *самое* святое место (Исх. 26:33) |
| שִׁ֫יר הַשִּׁירִים | «песня песней», что значит *величайшая* песня |
