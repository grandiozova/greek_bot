## 11.1 Введение

В библейском еврейском языке нет отдельного набора знаков для обозначения
чисел, поэтому числительные прописываются словами. В древнееврейском языке
есть **количественные** и **порядковые** числительные. Количественные
числительные обозначают количество чего-либо (один, два, три), порядковые
обозначают номер предмета при счёте (первый, второй, третий).

## 11.2 Количественные числительные: от 1 до 10

Эти числительные имеют по две формы: для мужского рода и для женского. Они
встречаются как в абсолютной, так и в сопряжённой форме. Выучите абсолютные
формы мужского рода. Особое внимание уделите написанию чисел **один** и **два**.

| | Муж. абс. | Муж. сопр. | Жен. абс. | Жен. сопр. |
|---|---|---|---|---|
| Один | ⟨dx'a,⟩ | ⟨dx;a;⟩ | ⟨tx;a;⟩ | ⟨tx;a;⟩ |
| Два | ⟨~yIn:ñv.⟩ | ⟨ynEv.⟩ | ⟨~yITñ;v.⟩ | ⟨yTev.⟩ |
| Три | ⟨vlov'⟩ | ⟨vlov.⟩ | ⟨hv'lov.⟩ | ⟨tv,lñov.⟩ |
| Четыре | ⟨[B;r>a;⟩ | ⟨[B;r>a;⟩ | ⟨h['B'r>a;⟩ | ⟨t[;Bñ;r>a;⟩ |
| Пять | ⟨vmex'⟩ | ⟨vmex]⟩ | ⟨hV'mix]⟩ | ⟨tv,mñex]⟩ |
| Шесть | ⟨vve⟩ | ⟨vve⟩ | ⟨hV'vi⟩ | ⟨tv,vñe⟩ |
| Семь | ⟨[b;vñ,⟩ | ⟨[b;v.⟩ | ⟨h['b.vi⟩ | ⟨t[;b.vi⟩ |
| Восемь | ⟨hn<mov.⟩ | ⟨hn<mov.⟩ | ⟨hn"mov.⟩ | ⟨tn:mov.⟩ |
| Девять | ⟨[v;Tñe⟩ | ⟨[v;T.⟩ | ⟨h['v.Ti⟩ | ⟨t[;v.Ti⟩ |
| Десять | ⟨rf,[,ñ⟩ | ⟨rf,[,ñ⟩ | ⟨hr"f'[]⟩ | ⟨tr<fñ,[]⟩ |

1. Форма мужского рода числительного *один* пишется с ⟨d⟩ (⟨dx'a,⟩), а форма
   женского рода с ⟨t⟩ (⟨tx;a;⟩). Числительное «один» имеет конструкцию
   прилагательного, поэтому оно ставится **после** определяемого
   существительного и согласуется с ним в роде и определённости.

[p. 86]

| | | | |
|---|---|---|---|
| ⟨dx'a, !Be⟩ | один сын | ⟨tx;a; tB;⟩ | одна дочь |
| ⟨dx'a,h' !Beh;⟩ | (этот) один сын | ⟨tx;a;h' tB;h;⟩ | (эта) одна дочь |
| ⟨~ynIB'h; dx;a;⟩ | один из сыновей | ⟨twOnB'h; tx;a;⟩ | одна из дочерей |

2. Форма мужского рода числительного «два» пишется с ⟨n⟩ (⟨~yIn:ñv.⟩), а форма
   женского рода с ⟨t⟩ (⟨~yITñ;v.⟩). Обе эти формы двойственного числа.
   Числительное «два» имеет форму существительного и **согласуется** в роде с
   существительным, к которому относится.

| | | | |
|---|---|---|---|
| ⟨~ynIB' ~yIn:ñv.⟩ | два сына | ⟨twOnB' ~yITñ;v.⟩ | две дочери |
| ⟨~ynIB' ynEv.⟩ | два сына | ⟨twOnB' yTev.⟩ | две дочери |

3. Числительные «три»–«десять», подобно числительному «два», имеют форму
   существительных, однако **не согласуются в роде** с теми существительными,
   с которыми они связаны. Другими словами, числительные мужского рода
   употребляются с существительными женского рода и наоборот.

| | | | |
|---|---|---|---|
| ⟨~ynIB' hv'lov.⟩ | три сына | ⟨twOnB' vlov'⟩ | три дочери |
| ⟨~ynIB' tv,lñov.⟩ | три сына | ⟨twOnB' vlov.⟩ | три дочери |

4. К сопряжённым формам числительных «два»–«десять» могут присоединяться
   местоименные суффиксы.

| | | | |
|---|---|---|---|
| ⟨~h,ynEv.⟩ | двое из них | ⟨!h,yTev.⟩ | двое из них |
| ⟨~k,ynEv.⟩ | двое из вас | ⟨!k,yTev.⟩ | двое из вас |
| ⟨WnynEv.⟩ | двое из нас | ⟨WnyTev.⟩ | двое из нас |

## 11.3 Количественные числительные: от 11 до 19

Числительные второго десятка образуются прибавлением слова «десять» к
соответствующему числительному первого десятка. Например, «одиннадцать» —
⟨rf'[' dx;a;⟩ — это сочетание числительных один (⟨dx'a,⟩) и десять (⟨rf,[,ñ⟩).

| | С сущ. муж. рода | С сущ. жен. рода |
|---|---|---|
| Одиннадцать | ⟨rf'[' dx;a;⟩ | ⟨hrEf.[, tx;a;⟩ |
| | ⟨rf'[' yTev.[;⟩ | ⟨hrEf.[, yTev.[;⟩ |

[p. 87]

| Двенадцать | ⟨rf'[' ynEv.⟩ | ⟨hrEf.[, yTev.⟩ |
| | ⟨rf'[' ~ynEv.⟩ | ⟨hrEf.[, ~yTev.⟩ |
| Тринадцать | ⟨rf'[' hv'lov.⟩ | ⟨hrEf.[, vlov.⟩ |
| Четырнадцать | ⟨rf'[' h['B'r>a;⟩ | ⟨hrEf.[, [B;r>a;⟩ |
| Пятнадцать | ⟨rf'[' hV'mix]⟩ | ⟨hrEf.[, vmex]⟩ |
| Шестнадцать | ⟨rf'[' hV'vi⟩ | ⟨hrEf.[, vve⟩ |
| Семнадцать | ⟨rf'[' h['b.vi⟩ | ⟨hrEf.[, [b;v.⟩ |
| Восемнадцать | ⟨rf'[' hn"mov.⟩ | ⟨hrEf.[, hn<mov.⟩ |
| Девятнадцать | ⟨rf'[' h['v.Ti⟩ | ⟨hrEf.[, [v;T.⟩ |

1. Альтернативная форма ⟨yTev.[;⟩ «одиннадцать» встречается в еврейской Библии
   лишь 19 раз.
2. В большинстве случаев эти числительные встречаются с существительными во
   множественном числе. Однако несколько существительных употребляются с ними
   в единственном числе, но при этом переводятся множественным числом.

| | |
|---|---|
| ⟨vyai rf'[' ynEv.⟩ | двенадцать человек (Иис. Нав. 3:12) |
| ⟨hn"v' hrEf.[, vlov.⟩ | тринадцать лет (3 Цар. 7:1) |
| ⟨~wOy rf'[' h['B'r>a;⟩ | четырнадцать дней (Исх. 12:6) |
| ⟨lq,v' rf'[' hV'mix]⟩ | пятнадцать шекелей (Лев. 27:7) |

| Пятый | ⟨yviymix]⟩ | ⟨tyviymix]⟩ |
| Шестой | ⟨yVivi⟩ | ⟨tyVivi⟩ |
| Седьмой | ⟨y[iybiv.⟩ | ⟨ty[iybiv.⟩ |
| Восьмой | ⟨ynIymiv.⟩ | ⟨tynIymiv.⟩ |
| Девятый | ⟨y[iyviT.⟩ | ⟨ty[iyviT.⟩ |

1. Порядковое числительное ⟨!wOvarI⟩ «первый» происходит от слова ⟨varo⟩
   «голова, глава, начало». Остальные порядковые числительные имеют общий
   корень с соответствующими им количественными числительными.
2. Формы мужского рода порядковых числительных «второй»–«десятый» отличаются
   от форм женского рода буквой ⟨t⟩ на конце. Числительные мужского рода
   оканчиваются на ⟨yi⟩, а женского рода на ⟨tyi⟩.
3. Порядковые имеют форму прилагательных: ставятся **после** определяемого
   существительного и, как правило, согласуются с ним в роде и определённости.

|---|---|
| ⟨!wOvarIh' ~wOYB;⟩ | в первый день (Лев. 23:7) |
| ⟨y[iybiV.h; ~wOYB;⟩ | в седьмой день (Быт. 2:2) |
| ⟨yViVih; ~wOy⟩ | день шестой (Быт. 1:31) |

4. Для обозначения порядковых числительных больше «десяти» используются их
   количественные соответствия.

| | |
|---|---|
| ⟨hn"v' hrEf.[,-vlov.W⟩ | и тринадцатый год (Быт. 14:4) |
| ⟨hn"v' [b;v,w" ~yvilov.Bi⟩ | в тридцать седьмой год (Иер. 52:31) |
| ⟨~y[iB'r>a;h; tn:v.Bi⟩ | в сороковой год (1 Пар. 26:31) |

## 11.7 Краткое содержание главы

1. Количественные числительные обозначают количество, порядковые — номер
   предмета при счёте.
2. Количественные числительные имеют по две формы: для мужского рода и для
   женского; встречаются в абсолютной и сопряжённой форме.

[p. 90]

3. Числительное «один» имеет форму прилагательного, «два» — форму
   существительного. Числительные 3–10 **не согласуются в роде** с
   существительным, к которому относятся.
4. Числительные второго десятка образуются прибавлением слова «десять».
5. В составных числительных между десятками и единицами ставится союз ⟨w>⟩.
6. Порядковые числительные имеют форму прилагательных: муж. род на ⟨yi⟩, жен.
   род на ⟨tyi⟩.
